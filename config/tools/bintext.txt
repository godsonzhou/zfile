BinText 3.00
------------

Version 3.0 does not represent any major additional functionality to
previous versions of BinText, it simply signifies the fact that BinText
has been acquired by Foundstone (http://www.foundstone.com).

Version 3.00
------------

o  Fixed problem with copying text to clipboard.

----------------------------------------------------------------------

Version 2.08
------------

o  Fixed accidental duplication of items in Advanced view.


Version 2.07
------------

o  Proper handling of quoted paths on Windows 2000 
o  Right-click menu on advanced view to copy selection 
o  Slight speed improvement 


Version 2.05
------------

Not released.


Version 2.04
------------

o  Added a few more selected characters to the default filter
o  Visual changes to advanced mode
o  Added more key shortcuts
o  Further reduction of executable size (33K)


Version 2.03
------------

o  Bug fix. Filter was using repeat count even when not selected to be used
o  Overall speed improvement in scanning
o  Dramatic speed improvement in non-advanced mode scan and display
o  Added display of time taken for scan and size of extracted text
o  Further reduction of executable size (36K)


Version 2.02
------------

o  Bug fix. Filters weren't displaying on initial viewing of the filter page.
o  Defaults to showing advanced view
o  Speed improvement in searching
o  Now only outputs one type of display at a time rather than doing advanced
   and standard view outputs together as in the previous version.


Version 2.01
------------

o  Bug fix. Advanced mode checkbox problem and window updating fixed.


Version 2.00
------------

o  Internal rewrite.
o  Main window no longer based on dialog box.
o  Defaults to simple text editor style view of the found text.
   The detailed view is now viwed by selecting the "advanced view" checkbox.
o  Bug fixes.
